# Snout & About

Snout & About is a responsive React application designed to help users (dogs, in this case) discover and connect with a dogs in a fun, engaging way. The project simulates a dog-matching platform where users can browse dog profiles, view details, manage a personal profile, and enjoy dog-related content powered by a third-party API.

## Features

- Responsive design for desktop, tablet, and mobile
- Browse dog profiles with photos and bios
- Interactive modals for viewing images and details
- User profile page with:
  - Editable profile information
  - Profile picture
  - Photo gallery
  - Optional Spotify theme song embed
- Authentication flow (mocked frontend logic)
- Random dog facts fetched from a third-party API
- Loading and error states for API requests
- Accessible modals with ESC and overlay close support
